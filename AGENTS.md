# Five-hour fitness integration

Этот блок добавляется в существующий `AGENTS.md` проекта. Он не заменяет и не отменяет другие инструкции.

## Учёт рабочих сессий

Для содержательных рабочих сессий применяется навык `five-hour-fitness` из подключённого каталога навыков.

- В начале сессии читается состояние журнала.
- Если есть невыполненное назначение упражнений, новая содержательная работа начинается только после явного подтверждения выполнения.
- Для коротких уточнений, исправлений журнала и малых служебных правок допускается provisional-режим без слова «приступил».
- В конце ответа всегда выводится короткая строка `Fitness`, даже при нулевом расходе.
- Журнал и упражнения ведутся только в пределах текущего проекта; личные записи не публикуются и не переносятся автоматически.

Навык сам определяет корень проекта по `SPEC/project.json` или этому маркеру и использует `logsDir` из конфигурации либо каталог `Логи` по умолчанию.
